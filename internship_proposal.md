# Internship Proposal

## 1. Project Aim
The aim of this project is to develop a robust, scalable, and efficient backend infrastructure for a bespoke architecture firm website. The backend will serve as the core engine that manages the firm's portfolio, client inquiries, and content delivery, ensuring seamless integration with the frontend while strictly adhering to the client's provided reference websites and design preferences.

## 2. Project Objectives
- **API Development:** Design and implement secure RESTful APIs to handle dynamic content such as architectural projects and contact form submissions.
- **Database Management:** Set up and optimize a lightweight relational database (SQLite) to store and manage website data efficiently.
- **System Architecture:** Build a modular and maintainable backend architecture using the NestJS framework to support future scalability.
- **Frontend Integration:** Collaborate closely with the frontend developer to ensure smooth data communication between the user interface and the server.

## 3. Expected Outcomes
- A fully functional backend system that reliably powers the architecture website.
- Secure and optimized API endpoints for the `projects` and `contact` modules.
- A well-structured SQLite database schema tailored to the specific data requirements of an architectural portfolio.
- High-quality, maintainable backend code written in TypeScript, following industry best practices.

## 4. Role in Project
**Role:** Backend Developer

**Responsibilities:**
As the Backend Developer, my primary focus will be on the server-side logic and database management. My responsibilities include:
- Setting up the backend development environment using the **NestJS** framework.
- Designing and implementing the database schema using **SQLite**.
- Developing modular components, including controllers, services, and modules for core features like `contact` and `projects`.
- Handling data validation, error handling, and core business logic.
- Providing structured API endpoints for the frontend application to consume and display architectural projects and handle user inquiries.

*(Note: The frontend development is handled separately by a team member.)*

## 5. Tools and Facilities
To successfully execute the backend development, the following tools and technologies will be utilized:
- **Framework:** NestJS (A progressive Node.js framework for building efficient and scalable server-side applications)
- **Programming Language:** TypeScript
- **Database:** SQLite (Lightweight, disk-based database)
- **Runtime Environment:** Node.js
- **Development & Testing:** Visual Studio Code, Postman (for API testing), Git/GitHub (for version control)
- **Code Quality:** ESLint and Prettier

## 6. Project Schedule
- **Week 1-2: Requirement Analysis & Setup**
  - Analyze reference websites and define data requirements.
  - Initialize the NestJS project and set up the development environment.
- **Week 3-4: Database Design & Core Modules**
  - Design the SQLite database schema.
  - Develop the `projects` module (CRUD operations for portfolio).
  - Develop the `contact` module (handling client inquiries).
- **Week 5-6: API Refinement & Integration**
  - Refine API endpoints, implement data validation, and error handling.
  - Collaborate with the frontend developer for API integration and testing.
- **Week 7-8: Testing, Deployment, & Documentation**
  - Conduct thorough backend testing (unit and integration tests).
  - Prepare the backend for deployment.
  - Finalize code documentation and project handover.
